Paso 1) Análisis demográfico de Ruzafa

Hay mucha vivienda pequeña y hogares reducidos: 12.213 hogares, con 5.285 hogares de una persona y 3.286 de dos personas; juntos son aproximadamente el 70% del total. La competencia es muy alta. TheFork lista 57 restaurantes en Ruzafa, con una oferta muy variada: americano, argentino, japonés, indio, chino, mediterráneo, fusión, mexicano y alta cocina. En su primera página aparecen desde propuestas de 20–25 € hasta restaurantes de 75–140 € de precio medio.

Riesgo 2: saturación competitiva. Hay demasiada oferta similar y mucha visibilidad digital. La amenaza está en pagar demasiado por un traspaso, entrar sin licencia segura o abrir algo indiferenciado. import tkinter as tk
import re

# Crear la ventana principal
ventana = tk.Tk()
ventana.title("Calculadora")
ventana.geometry("300x400")
ventana.resizable(False, False)

# Variable donde se guarda lo que escribe el usuario
operacion = ""


def presionar_boton(valor):
    global operacion
    operacion += str(valor)
    pantalla.delete(0, tk.END)
    pantalla.insert(0, operacion)


def borrar():
    global operacion
    operacion = ""
    pantalla.delete(0, tk.END)


def calcular():
    global operacion

    try:
        # Permitimos solo números y operadores seguros
        if not re.fullmatch(r"[0-9+\-*/(). ]+", operacion):
            pantalla.delete(0, tk.END)
            pantalla.insert(0, "Error")
            operacion = ""
            return

        resultado = eval(operacion, {"__builtins__": None}, {})
        pantalla.delete(0, tk.END)
        pantalla.insert(0, str(resultado))
        operacion = str(resultado)

    except:
        pantalla.delete(0, tk.END)
        pantalla.insert(0, "Error")
        operacion = ""


# Pantalla de la calculadora
pantalla = tk.Entry(
    ventana,
    font=("Arial", 24),
    justify="right"
)
pantalla.pack(fill="both", padx=10, pady=10, ipady=10)


# Frame para los botones
frame_botones = tk.Frame(ventana)
frame_botones.pack()


# Lista de botones
botones = [
    "7", "8", "9", "/",
    "4", "5", "6", "*",
    "1", "2", "3", "-",
    "0", ".", "=", "+"
]


fila = 0
columna = 0

for boton in botones:
    if boton == "=":
        accion = calcular
    else:
        accion = lambda valor=boton: presionar_boton(valor)

    tk.Button(
        frame_botones,
        text=boton,
        font=("Arial", 18),
        width=5,
        height=2,
        command=accion
    ).grid(row=fila, column=columna, padx=2, pady=2)

    columna += 1

    if columna > 3:
        columna = 0
        fila += 1


# Botón borrar
tk.Button(
    ventana,
    text="Borrar",
    font=("Arial", 18),
    width=20,
    height=2,
    command=borrar
).pack(pady=10)


# Ejecutar la ventana
ventana.mainloop()
